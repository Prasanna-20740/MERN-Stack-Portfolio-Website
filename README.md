# 🚀 MERN Stack Portfolio Website

A modern, responsive, and professional personal portfolio website developed using the **MERN Stack (MongoDB, Express.js, React.js, and Node.js)**. This portfolio showcases my technical skills, projects, internship experience, certifications, and professional profile.

🌐 **Live Demo:** https://mern-stack-portfolio-website-khaki.vercel.app/

## 📌 About the Project

The MERN Stack Portfolio Website is designed to build my professional online presence and highlight my development journey. It provides visitors and recruiters with an overview of my technical expertise, completed projects, work experience, and achievements.

## ✨ Key Features

- **Responsive Design** – Compatible with desktop, tablet, and mobile devices.
- **Professional Profile** – Displays personal information and career objectives.
- **Technical Skills** – Showcases programming languages, frameworks, and tools.
- **Projects Showcase** – Displays completed development projects.
- **Internship Experience** – Highlights professional training and experience.
- **Certifications** – Showcases completed courses and certifications.
- **Contact Information** – Provides ways to connect professionally.
- **MERN Stack Architecture** – Uses frontend and backend technologies.

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/Prasanna-20740/MERN-Stack-Portfolio-Website.git
```

**2. Navigate to the project**

```bash
cd MERN-Stack-Portfolio-Website
```

**3. Install dependencies**

Navigate to the frontend and backend folders separately and install their dependencies.

```bash
npm install
```

**4. Configure Environment Variables**

Configure the required environment variables for your MongoDB connection and backend configuration.

**5. Run the application**

Start the frontend and backend using their respective development scripts.
